# Privacy Policy for The Current

Last updated: 7 October 2026

The Current is a personalised newsfeed extension for Microsoft Edge. This policy explains what information the extension accesses, how that information is used, and the controls available to the user.

## Information accessed

The Current may access:

- URLs and titles of active browser tabs when optional reading tracking is enabled.
- Estimated time spent on pages that appear to be news articles.
- Up to 90 days of browser-history entries only when the user manually chooses the history-import feature and confirms the action.
- News-source settings, exclusions, feedback, paywall preferences, cached feed items, and hidden article URLs.
- Public RSS feeds and publisher webpages configured as news sources.

## How information is used

This information is used only to:

- Fetch and display recent stories from configured sources.
- Rank stories using recency, explicit feedback, and optional reading activity.
- Apply user-selected exclusions and paywall preferences.
- Diagnose whether configured news feeds are working.

## Storage and disclosure

Reading activity, settings, feedback, and source configuration are stored locally in Microsoft Edge extension storage. The Current has no developer-operated server, account system, advertising platform, or analytics service. It does not sell reading information or transmit it to the developer.

When the extension fetches an RSS feed or public publisher page, the request goes directly from Microsoft Edge to that publisher. The publisher may receive ordinary network information associated with a web request, including the user's IP address, in accordance with the publisher's own privacy policy.

An exported JSON file is created only when the user selects Export JSON. The user controls where that file is saved and how it is handled.

## User controls

Users can:

- Leave reading tracking disabled.
- Enable or disable reading tracking at any time.
- Choose whether to import browser history.
- Exclude URL fragments from tracking.
- Add or remove news sources.
- Export locally stored data.
- Clear stored reading history and feedback.
- Remove the extension and its locally stored data through Microsoft Edge.

## Data retention

Locally stored information remains until the user clears it, removes the extension, or Microsoft Edge removes the extension's storage. The extension limits its reading-interest calculations to recent activity and caps the number of stored visit records.

## Security

The extension requests HTTPS resources and uses Microsoft Edge's extension storage. No method of storage is guaranteed to be completely secure, but The Current minimises exposure by keeping personalised data on the user's device and not operating a remote data-collection service.

## Changes

This policy will be updated when the extension's functionality or data practices change. The updated date at the top of this document identifies the latest revision.

## Contact

Support and privacy enquiries can be submitted through the private project owner or the support contact supplied in the Microsoft Edge Add-ons listing.
